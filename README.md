# Herbie

Flow-native automotive simulation and manufacturing engineering.

Herbie is being built as an allocation-free, explicitly stepped simulation library for vehicle dynamics, controls, stress analysis, and manufacturing tolerance analysis. Engineering equations and limits must be traceable to tests and assumptions before production use.

**Status:** repository initialisation. The implementation is developed in pull requests.

Language: [Flow](https://github.com/flooooooooooow/flow).

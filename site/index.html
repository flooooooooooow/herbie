MODEL INTEGRITY

What is simulated, and what is not

Dynamic, live: throttle-to-tractive-force mapping, shift heuristic, aerodynamic drag, rolling resistance, road grade, 2D linear bicycle dynamics with an approximate friction circle, front/rear representative RK4 quarter-car response, engine and brake lumped heating, and diagnostic force/stress readouts.

Manufacturing: worst-case interval clearance with differential thermal expansion, seeded independent-normal assembly sampling, empirical pass fraction and sample Cpk. The applied tolerances are for a demonstration fit, not actual vehicle CAD geometry or a complete GD&T stack.

Excluded: detailed parts, gear/clutch transients, tyre slip relaxation, axle pitch/roll, kinematic hard-points, nonlinear contacts, FEA, combustion and cooling networks, BMS, power electronics, emissions, certified material properties or qualified real-time timing. The chassis stress is a scalar illustrative force/area calculation, not a structural assessment.

The browser engine is a JavaScript reference port of Herbie-style reduced-order equations, not a Flow/WASM build. Flow source modules and Flow native regression suites remain the authoritative library work. No engineering decisions or safety claims should be based on this demo.
